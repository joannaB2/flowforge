# FlowForge

Visual form and workflow automation platform.

FlowForge is a portfolio project focused on building complex,
interactive web applications with React and TypeScript.

## Project goals

The application will allow users to:

- build forms using a visual editor
- create automation workflows using a node-based interface
- define conditions and actions
- execute workflows
- inspect execution history

## Planned stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Flow
- Zustand
- React Hook Form
- Zod
- PostgreSQL
- Drizzle ORM
- Playwright
- Vitest
